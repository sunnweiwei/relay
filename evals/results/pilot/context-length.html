Context-management methods by task context length

gpt-6-luna, medium reasoning effort, full-population runs on three benchmarks. Generated 2026-11-06. Only runs under one budget condition per benchmark are included; see evals/pilot/README.md for the protocol and its limitations.

1. Runs

  • BrowseComp-Plus: 5,757 ended runs of 8 methods; 48 task failures scored 0; 140 infrastructure failures excluded.
  • ARC-AGI-3: 133 ended runs of 6 methods; 0 task failures scored 0; 8 infrastructure failures excluded.
  • Terminal-Bench-Science: 383 ended runs of 8 methods; 3 task failures scored 0; 23 infrastructure failures excluded.
Context length. A run's unmanaged context length is the token count of Codex's own full history at the end of the run, before any method rewrites it: how long the context would be without context management. A task's context demand is the median unmanaged length of the five core methods (Compaction, Folding, CLM, ACM, Self-Compact) on that task. Longer tasks also tend to be harder, so a falling curve mixes longer context with harder tasks; comparisons between methods on the same tasks are less affected.
Truncation fallback. All runs used Relay's common overflow fallback: when a method's own forced recovery still left a request over the window, Relay dropped the oldest tool call groups. Released ACM has no forced recovery and the model rarely asked it to compress, so ACM needed the fallback in most runs, the other methods almost never (column "Runs with truncation fallback"). Two methods added on 2026-11-06 separate the two parts on Browse and Science: Truncation only leaves the context unchanged, so the fallback alone manages it, and ACM (forced) compresses, as manage_context does, the oldest history since its last summary when a request is over the window. They ran on 2026-11-06, a week after the other methods, until the account's weekly usage limit stopped them: on 404 and 403 of the 825 Browse questions (the first in the fixed random order) and on 23 Science tasks. A same-day rerun of released ACM, meant to measure drift between the two dates, was rejected by the account limit before any run, so the drift is not measured.
RLM is not a measurement of the RLM method. Relay replaces the conversation with the RLM's handoff, and in many runs the main agent never sees the task (its final answer asks for the question). RLM is drawn for reference and is left out of the paired comparisons.
